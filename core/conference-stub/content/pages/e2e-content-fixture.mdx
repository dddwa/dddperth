**This page is a test fixture.** It exists so the visual regression suite can
screenshot the MDX content template without depending on real editorial copy.
`/about` was used for that before, which meant any wording change to a genuine
page failed an unrelated visual baseline.

Treat the content below as frozen. Changing it will fail the visual suite —
which is the point, but it should only ever happen deliberately, when the
content *template* changes rather than when someone edits a real page.

## Headings and prose

This paragraph exercises ordinary body copy, wrapping behaviour and the

sentences so that the rendered block is tall enough to show a genuine
difference if the type scale, measure or spacing ever shifts.
